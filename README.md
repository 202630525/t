# 🗺️ Territorial.io Web Clone

A lightweight, high-performance HTML5 Canvas implementation of **Territorial.io**, built with pure Vanilla JavaScript and zero external dependencies.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Deploy with GitHub Pages](https://img.shields.io/badge/Deploy-GitHub%20Pages-blue.svg)](https://pages.github.com/)

---

## 🌟 Features

* **Pixel-Buffer Canvas Engine:** Fast `ImageData` pixel array rendering capable of processing real-time map updates across thousands of pixels.
* **Interest-Based Troop Economy:** Exponential troop growth balanced by a territory-based carrying capacity ceiling.
* **BFS Frontier Conquest:** Real-time Breadth-First Search (BFS) expansion algorithm for organic map expansion.
* **Attack Slider:** Adjust troop deployment ratios (1%–100%) for tactical invasions.
* **AI Bot Competitors:** Autonomous bots that manage interest, defend land, and launch invasions against player borders.
* **Zero Build Steps:** Single `index.html` structure—ready to run locally or deploy to static web hosts instantly.
